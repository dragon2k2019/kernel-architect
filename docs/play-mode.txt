KERNEL ARCHITECT — PLAY MODE, rendered as text.

The same game with the numbers taken out: every request is a picture, every box is a thing, the goal is a
row of pictures filling up and the error budget is five hearts. These are real frames of the running game,
dumped by tools/shot.mjs (the HUD is a 160x50 cell grid, so it can be printed to a terminal):

    node tools/shot.mjs --screen kid --level K01 --plain
    node tools/shot.mjs --screen kid --level K01 --tour --plain
    node tools/shot.mjs --screen kidend --level K03 --plain

Colour is lost here; in the game each picture keeps the colour of the thing it stands for, the picking /
placing rows are highlighted, and the pictures inside the boxes are drawn at double size.
